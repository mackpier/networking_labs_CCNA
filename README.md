# Cisco Packet Tracer Networking Labs

## Overview

This repository showcases a collection of Cisco Packet Tracer networking labs completed as part of my networking and IT support training. These labs demonstrate hands-on experience with enterprise networking concepts including routing, switching, IPv4/IPv6 addressing, network security, wireless networking, troubleshooting, and Cisco IOS device configuration.

## Skills Demonstrated

- Cisco Router Configuration
- Cisco Switch Configuration
- IPv4 & IPv6 Networking
- VLANs
- SSH & Telnet
- Access Control Lists (ACLs)
- Wireless Security
- NAT
- FTP Services
- CDP
- Network Troubleshooting
- Routing
- Switching
- Network Documentation
- Wireshark Packet Analysis
